### Project Description
Sloth OS is a browser-based, Linux-inspired operating environment built with Next.js, React, and TypeScript. It looks and behaves like a modern desktop OS—with windows, a taskbar/dock, applications, a terminal, filesystem, notifications, system monitoring, and settings—but its entire purpose is to do the opposite of a normal operating system

### The Problem (that doesn't exist)
People are becoming dangerously productive and actually finishing their work.

### The Solution (that nobody asked for)
Sloth-OS detects productivity and immediately interrupts the user with distractions, useless activities, and warnings to make sure absolutely nothing gets done.
